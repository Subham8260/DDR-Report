# DDR AI Report Generator

## Overview
This project is an AI-powered system that converts inspection and thermal reports into a structured Detailed Diagnostic Report (DDR).

## Features
- Upload inspection + thermal PDFs
- AI extracts key observations
- Combines data logically
- Generates structured DDR output

## Tech Stack
- HTML, CSS, JavaScript
- Claude API (AI model)

## How it works
1. User uploads two PDF reports
2. Files are converted to Base64
3. Sent to AI model
4. AI processes and returns structured JSON
5. UI renders final DDR report
